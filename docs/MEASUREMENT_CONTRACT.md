# Measurement Contract — v0.1.0

This repository is a mechanistic laboratory, not evidence that PCC has been established in fighting games.

## Core design rule

Pressure, Control, and Chaos are **latent policy mechanisms**, not move labels. The legal action set is shared by every policy:

- advance
- retreat
- attack
- guard
- evade

## Provisional structural hypotheses

- **Pressure candidate:** spatial commitment -> opponent option/space constriction -> strategic consequence.
- **Control candidate:** public-history uptake -> context-sensitive response selection -> value-sensitive intervention.
- **Chaos candidate:** behavioral unpredictability x independent performance adequacy.

The v0.1 observables are descriptive only. They are not validated PCC coordinates.

## Explicit non-claims

- action entropy is not Chaos by itself;
- attack frequency is not Pressure by itself;
- history use is not Control by itself;
- a matchup cycle is not required and will not be tuned into existence;
- graphical presentation and human reaction time are outside v0.1.
