# Validation Roadmap

1. v0.1 — legal deterministic simulator, neutral baseline, provisional policy mechanisms, descriptive observables.
2. Freeze a balance/competitiveness protocol across independent seeds and seat/order swaps. Do not require a rock-paper-scissors cycle.
3. Implement a second independent policy family before construct recovery.
4. Test Pressure as spatial commitment -> response/space constriction -> consequence.
5. Test Control as information -> context alignment -> intervention.
6. Test Chaos with value-preserving unpredictability and exploitability/performance guards.
7. Only after those synthetic tests should the environment be added to `pcc-cross-game`.
8. A graphical/playable layer may be added later but must remain separable from the headless scientific core.
